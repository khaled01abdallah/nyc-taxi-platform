# NYC Taxi Analytics Platform

A data engineering portfolio project: an analytics platform built on NYC taxi
data, using Databricks, dbt, Airflow, Terraform and AWS.

**Status:** Phase 1 (batch core) in progress.

## What it does

Combines three sources into one trusted analytics layer:

| Source | Content | Role |
|---|---|---|
| Public S3 bucket | NYC TLC yellow taxi trips (Parquet) | Large batch facts |
| CSV file | Taxi zone lookup | Reference dimension |
| PostgreSQL | Vendors, vendor contracts, fare disputes (simulated) | Changing operational data |

Data flows through a medallion architecture (bronze, silver, gold) on
Databricks. dbt builds the star schema, and Airflow orchestrates the runs.

## Tech stack

## Getting started

Requires Python 3.11+ and Docker.

```bash
python -m venv .venv
source .venv/Scripts/activate   # Git Bash on Windows
# .venv\Scripts\Activate.ps1    # PowerShell
pip install -e ".[dev]"
python -m pytest -q
ruff check . && ruff format --check .
```

Build and run the Docker image:

```bash
docker build -f docker/Dockerfile -t nyc-taxi-ingestion .
docker run --rm nyc-taxi-ingestion
```

data. The PostgreSQL data is synthetic and generated by a script in this repo.
